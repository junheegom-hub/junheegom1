# 버튼 앱 (Button App)

## 앱 소개
버튼 앱은 버튼을 누르면 색상과 안내 문구가 바뀌는 간단한 인터랙티브 앱입니다.

## 주요 기능

### 1. 처음 화면
- 파란색 버튼이 표시됩니다.
- 버튼 문구: `버튼을 눌러보세요`

### 2. 버튼을 눌렀을 때
- 버튼 색상이 초록색으로 변경됩니다.
- 문구가 `버튼이 눌렸습니다`로 변경됩니다.

### 3. 버튼을 다시 눌렀을 때
- 버튼 색상이 파란색으로 돌아옵니다.
- 문구도 `버튼을 눌러보세요`로 돌아옵니다.

## 작동 방식
버튼을 누를 때마다 두 가지 상태가 번갈아 나타납니다.

- 🔵 파란색: 기본 상태
- 🟢 초록색: 눌린 상태

## 개발 정보
- 개발 언어: HTML
- 데스크톱 앱 제작: Electron
- 빌드 도구: electron-builder
- 저장소: GitHub
